# Makerspace Factory Patterns

Assignment 2: Factory Method and Abstract Factory.

## Proposed domain

A university makerspace that handles fabrication jobs.

## Planned original families

- 3D printing
- Laser cutting
- Vinyl cutting

## Planned product types

- FabricationJob
- Machine
- MaterialCatalog

## Development approach

First implement a small version without factories.
Then refactor it using Factory Method and Abstract Factory.
